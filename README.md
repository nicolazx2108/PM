# App Scholar

## Sobre o projeto

O App Scholar é uma aplicação acadêmica desenvolvida para auxiliar no gerenciamento de informações escolares, permitindo organizar alunos, responsáveis, professores, cursos, turmas, disciplinas, matrículas e avaliações.

O projeto foi desenvolvido como parte do curso Técnico em Desenvolvimento de Sistemas.

## Funcionalidades

* Cadastro de alunos
* Consulta de alunos
* Edição de informações dos alunos
* Exclusão de alunos
* Gerenciamento de responsáveis
* Gerenciamento de professores
* Gerenciamento de cursos
* Gerenciamento de turmas
* Gerenciamento de disciplinas
* Gerenciamento de matrículas
* Gerenciamento de avaliações
* Consulta de boletins

## Tecnologias utilizadas
